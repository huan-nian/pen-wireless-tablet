# 无线手写板 v0.1.0（预览版）

把 Android 平板当作电脑的**无线手写板**：平板用触控笔书写，笔迹以真正的
Windows Ink 注入电脑，Photoshop、OneNote、画图、Krita 等支持压感的软件都能直接画。
不用装驱动、不用数据线，只要两边在同一个局域网。

## 下载哪个

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `PenReceiver-0.1.0-win-x64.zip` | 约 69 MB | **推荐**。接收端，自包含，电脑上**不用装 .NET** |
| `PenReceiver-0.1.0-win-x64-lite.zip` | 约 6 MB | 同上但体积小得多，需要电脑已装 .NET 8 运行时 |
| `PenClient-0.1.0-debug.apk` | 约 7 MB | 平板端。debug 签名，安装时请允许「未知来源」 |

## 三步用起来

1. **电脑端**：解压接收端压缩包，双击 `launch-receiver.cmd`，在 UAC 窗口点「是」。
   首次运行请在防火墙提示里允许**专用网络**（UDP 入站）。启动后会自动开始监听，
   窗口里会显示本机 IP。
2. **平板端**：安装 APK，打开后点「**扫描电脑**」→ 出现电脑地址 → 点「**连接**」。
3. **开始写**：点右下角「**开始书写**」进入书写页，用触控笔在白色区域书写即可。

> 必须提权才能运行接收端：Windows 的笔输入注入接口只在提升后的进程里可用，
> 这是系统设计，不是本项目的选择。

## 平板书写页的功能

左侧一列快捷按钮，直接控制电脑：

| 按钮 | 动作 |
| --- | --- |
| 桌面 | `Win + D` 最小化所有窗口 |
| 多任务 | `Win + Tab` 任务视图（窗口与虚拟桌面） |
| 保存 | `Ctrl + S` |
| 撤销 / 取消撤销 | `Ctrl + Z` / `Ctrl + Y` |
| 滚轮上 / 下 | 鼠标滚轮 |
| 详情 | 返回连接页（本地） |
| 关闭 | 退出应用（本地） |

底部两个开关：

- **背景**：书写区底色，9 种预设（暖白、护眼米黄、浅灰、豆沙绿…）；
- **笔迹永存 / 5 秒 / 10 秒 / 1 分钟**：停笔后自动清空**平板上**的笔迹，
  电脑上的笔迹不受影响。

书写行为：整块画布映射到电脑主屏，指哪写哪；手指触摸完全忽略（防手掌误触）；
笔尖离屏约 1cm 就上报位置，电脑上提前出现笔光标；
**笔尖按住不动约 0.6 秒即长按，松开后电脑上弹出右键菜单**。

## 已知限制（预览版请务必先看）

- **触控笔必须是真压感笔**。手指、普通电容笔都不行——本项目只采集
  `TOOL_TYPE_STYLUS` / `TOOL_TYPE_ERASER`。
- **压感取决于电脑端**。如果电脑没有被 Windows 识别为笔设备的数字化屏，
  压力上界只有 1，只能表达「有压力 / 无压力」，画不出粗细变化。接收端启动时会
  实测上界并显示在界面上。有真笔数字化器的电脑会自动用上满量程。
- **只映射整块主屏**，不支持映射到指定窗口或区域，也没有坐标校准。
- **平板锁定横屏**，竖屏书写未做旋转映射。
- **局域网明文**：报文没有加密或鉴权，同网段设备可以伪造笔输入与快捷键。
  接收端提供「只接受指定平板地址」的来源限制开关，建议开启。
- 单指单笔，不支持多笔同时书写；笔身按键（barrel button）未映射。

## 运行环境

- Windows 10 1809 及以上（笔注入接口要求目标框架 `10.0.19041` 以上）。
- 平板 Android 8.0（API 26）及以上，与电脑在同一局域网。
- 防火墙需放行 UDP 8888 入站（端口可在接收端界面修改）。

## 遇到问题怎么办

按代价从低到高有三层排查：

1. 双击 `selftest.cmd`（在压缩包里）——不需要管理员权限，也不会干扰你的鼠标键盘。
   85 项断言覆盖协议、坐标映射、压力缩放、长按状态机、快捷命令映射。
   全部通过时退出码为 0。
2. 看接收端界面：「注入权限」显示「正常（已成功注入）」说明提权成功；
   「暂停注入」可以区分「网络不通」和「注入失败」；
   「数据速率 / 丢包 / 兜底抬笔」能看出链路在哪一段出问题。
3. 跑 `probe.cmd`（需要管理员）——它会绕过平板与网络，直接用接收端同一份注入代码
   把一条曲线画进画图并截图对比。**能画出线说明问题在平板或网络，画不出说明在注入。**
